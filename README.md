# Fernanda Site

Site público de `fernandafsoares.com.br`, separado dos sistemas internos e dos
dados de leads. O formulário funciona no navegador e encaminha a solicitação ao
WhatsApp; não existe banco público de contatos.

## Acessos

- Zoho Mail: serviço externo oficial.
- LinkedIn profissional: `https://www.linkedin.com/in/fernanda-soares-02aa25269/`.
- Radar de Perícias: `radar.fernandafsoares.com.br`, protegido por Cloudflare Access.
- Estúdio de Conteúdo: `studio.fernandafsoares.com.br`, protegido por Cloudflare Access.

Os subdomínios internos dependem do notebook ligado, dos serviços locais e do
Cloudflare Tunnel. Nenhum dado privado é armazenado neste repositório público.
